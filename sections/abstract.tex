\begin{abstract}
The substantial computation and memory demands of large language models (LLMs) often require inference across multiple devices. Model partitioning and communication strategies shape how soft errors propagate between devices, while dependencies between generated tokens can carry corruption across decoding steps and amplify its impact. Existing model-level fault-injection tools provide limited support for the parallel execution details governing these propagation paths. We present vLLM-FI, a fault-injection and reliability-evaluation framework built on vLLM. It models memory, computation, and communication faults using runtime workloads and communication buffers, coordinates injection across distributed workers, and supports quantized inference. GPU-resident bit flips and standardized task evaluation enable efficient reliability studies under practical execution configurations. Experiments reveal that parallelization strategy and device position affect fault-induced degradation. Under native communication workloads at a bit error rate of $10^{-8}$, pipeline parallelism retains 4.64 percentage points more normalized task performance than tensor parallelism on average across the evaluated model--task pairs. In the tested four-device configurations, the compared tensor-parallel ranks exhibit similar degradation, whereas earlier pipeline stages are more sensitive to memory faults and later stages to compute faults. These findings show why reliability evaluation must account for communication behavior and model partitioning, and inform the placement of selective protection. Calibration against MRFI yields a maximum difference of 0.62 percentage points in fault-injection correct rate, while evaluated end-to-end workloads achieve a $1.81\times$--$2.41\times$ speedup, supporting broader evaluation at lower experimental cost.
\end{abstract}
